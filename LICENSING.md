# Licensing

VibeUs uses different licenses for the server-side platform and the embeddable web client.

| Component | Path | License |
| --- | --- | --- |
| Backend | `openspec-core/**` | AGPL-3.0-only |
| CLI / local bridge | `openspec-cli/**` | AGPL-3.0-only |
| Web app and embeddable widget | `openspec-web/**` | MIT |
| Compiled widget assets | `openspec-core/static/vibus-widget.umd.cjs`, `openspec-core/static/vibus-widget.css` | MIT |
| Documentation | `docs/**` | CC-BY-4.0 |

## Embedding the widget

The embeddable VibeUs web client is MIT-licensed. Loading or embedding the widget in a proprietary or commercial website does **not** require the website itself to be released as open source.

## Backend and CLI

The backend and CLI are AGPL-3.0-only. See the license files in the repository for the full terms.
