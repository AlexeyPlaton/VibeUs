# VibeUs Quality Gate v6 — Engineering Criteria Contract v2

Этот gate защищает DoD-механику от деградации обратно в самосертифицируемый checkbox-list.

## Обязательные свойства

- AI-facing prompts are English-only and contain Engineering Execution Contract v2.
- Golden Catalog contains at least 55 canonical engineering criteria/preset identifiers.
- Criteria encode severity, applicability, verification, pass condition, negative case/positive control where applicable, artifacts and forbidden shortcuts.
- Critical risk profiles exist for bugfix, API, auth/security, DB, migration, concurrency, external integration, billing/refunds, UI, privacy, background jobs, files, realtime and deployment.
- AI DoD generation returns structured JSON, not a 4–6 string wishlist.
- `.vibus/TASKS_FOR_AI.md` generated by both normal listen and Live Preview carries the same evidence rules.
- Existing human Review remains the final acceptance boundary.

## Run

```bash
python quality-gates/v6-criteria-contract/verify_contract_v2.py .
```

Then run native frontend/CLI tests and builds.
