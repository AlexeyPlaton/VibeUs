# VibeUs public release gates

This public tree keeps the release-contract suites used by `run_release_gate.py`:

- `v3.3.2-final-semantics`
- `v4-release-integrity`
- `v5-billing-ledger-closure`
- `v6-criteria-contract`
- `v6.1-evidence-closure`
- `v6.2-trusted-evidence`
- `v7-i18n-global-launch`

Older forensic gate generations are retained only in the private canonical development repository.
They are intentionally omitted from the first public source history because they contain historical
baselines, agent instructions, failure snapshots and other release archaeology rather than the
current supported release contract.
