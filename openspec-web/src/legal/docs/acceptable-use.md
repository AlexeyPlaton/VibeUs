# Правила допустимого использования VibeUs

Запрещено использовать сервис для:

- фишинга или выдачи Preview за production-страницу банка/платежного сервиса;
- кражи учетных данных, cookies, токенов или платежных реквизитов;
- распространения вредоносного кода;
- сканирования/доступа к системам без разрешения;
- обхода ограничений/блокировок третьих лиц;
- загрузки персональных данных без законного основания;
- обработки специальных/биометрических категорий, если VibeUs явно не поддерживает такой режим;
- нарушения прав третьих лиц и применимого законодательства.

VibeUs вправе автоматически ограничить публичный tunnel/access link при признаках abuse и запросить подтверждение законности использования.

Сообщения об abuse: `abuse@vibeus.pro`.
