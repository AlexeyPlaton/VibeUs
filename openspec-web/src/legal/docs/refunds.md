# Оплата, продление, отмена и возвраты VibeUs

**Версия:** 01.09.2026

## 1. Текущая модель

Платный доступ VibeUs предоставляется на 30 календарных дней. Продление выполняется вручную пользователем. Фоновое автоматическое списание без отдельного подключения recurring-функции не выполняется.

## 2. Раннее продление

Если следующий период оплачен до окончания текущего, 30 дней добавляются от текущей даты окончания, а не «сгорают» в день платежа.

## 3. Платежные реквизиты

VibeUs не хранит полный номер карты/CVC. Если платежный провайдер возвращает идентификатор сохраненного метода, VibeUs может хранить только такой идентификатор и только для предусмотренной функции.

Пользователь может отказаться от дальнейшего использования сохраненного метода через раздел биллинга в кабинете `/app` либо направив запрос на `support@vibeus.pro`. После отказа метод не используется для периодических платежей.

## 4. Автопродление в будущем

До включения автопродления интерфейс должен отдельно показать:

- сумму и периодичность;
- дату/принцип следующего списания;
- способ отключения;
- способ отказа от сохраненных реквизитов;
- порядок уведомления до списания;
- порядок возврата.

## 5. Возвраты

Возвраты рассматриваются с учетом статуса пользователя (потребитель/B2B), фактически оказанного объема, даты обращения и императивных требований законодательства.

Запрос на возврат: `support@vibeus.pro`, с указанием email аккаунта и идентификатора платежа YooKassa. Нельзя требовать у пользователя полный номер карты/CVC.

Формулировка «возвратов нет ни при каких обстоятельствах» не используется.
