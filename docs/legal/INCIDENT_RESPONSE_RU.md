# Внутренний Incident Response Playbook VibeUs

**Не публиковать как юридическое обещание без адаптации.**

## Severity

- **SEV-0:** подтвержденный несанкционированный доступ к секретам/данным нескольких tenants, активный compromise production.
- **SEV-1:** доступ к ПД одного tenant, payment/auth bypass, preview cross-origin compromise.
- **SEV-2:** ограниченный security defect без подтвержденного доступа к чужим данным.

## Первые действия

1. Зафиксировать время обнаружения и источник сигнала.
2. Назначить incident commander.
3. Сохранить forensic evidence, не распространяя ПД шире необходимого.
4. Ограничить compromise: revoke sessions/tokens, выключить tunnel/integration, изолировать ключ.
5. Определить категории субъектов, данные, tenants, временной диапазон.
6. Проверить, подпадает ли событие под уведомление по ч. 3.1 ст. 21 152-ФЗ.
7. Если VibeUs — обработчик по поручению, уведомить клиента-оператора без неоправданной задержки по DPA.

## Внешние сроки РФ

Если применима ч. 3.1 ст. 21 152-ФЗ, организационный процесс должен позволять выполнить первичное уведомление уполномоченного органа в течение 24 часов с момента выявления и предоставить результаты внутреннего расследования в установленный законом последующий срок (72 часа).

## После containment

- root cause;
- проверка похожих путей;
- rotation затронутых секретов;
- восстановление из проверенной точки;
- уведомления;
- regression test, который воспроизводит класс инцидента;
- postmortem без обвинительного тона;
- обновление threat model/release gate.
